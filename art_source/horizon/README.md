# Original horizon source

`python3 art_source/horizon/generate.py` writes the original reference panorama, native cubemap atlas and source/asset hash manifest to `game/art/assets/horizon/`. Installed Pillow/numpy are generation tools, not runtime dependencies. The generator is deterministic and has no external data, photographs, downloads, API calls or third-party content. Project owner controls the original outputs under the same scope as ART-001; no new public licence grant is implied.

The horizon is an atmospheric Glasgow-inspired composite: hills, woodland, tenement/slate/chimney rhythm, sparse modern/civic/industrial accents. It is not a surveyed panorama, exact shop/location claim or copied mural. The entire lower hemisphere is painted, with periodic azimuth and continuous poles. The existing high guard reuses the already registered resident CC0 brick albedo, without its normal map or another texture import. The first generated masonry tile was rejected as too bright/repetitive and is not shipped.

Runtime uses a single native cubemap lookup and existing wall geometry; no generator work occurs during play. Six512² uncompressed RGB8 faces with mipmaps have a≤6MiB combined image-data budget (expected6,291,450bytes). The4096×2048 panorama remains an offline reference, without a runtime preload. Face order is+X,−X,+Y,−Y,+Z,−Z, row-major in a3×2 atlas; pixel-centre bilinear sampling wraps the source azimuth. Actual import bytes, native captures, performance admission and rejection history belong in `docs/testing/horizon-background/`; generated appearance alone is not final art acceptance.
