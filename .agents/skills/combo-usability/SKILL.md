Read current AGENTS, STATUS, interfaces, the fidelity benchmark and FID-304. Reconcile main before diagnosing; current native gameplay is substantially newer than the October alpha. Coordinate skater.gd sections with motion/contact specialists and HUD sections with the integrator. Preserve Music isolation, all default trial content and no-spend rules.

Reproduce the user's actual difficulty through mapped input in ordinary Main. Record takeoff, accepted trick, manual request time, native floor contact, link events, bank events, bails and input release. Compare a useful early/late landing-input matrix with stale-held, cancelled, paused and ineligible controls. A nominal catalogue entry or direct manual_active assignment is not evidence of a joined combo.

Use fresh, bounded input buffering. Never extend a score deadline through an invalid trick or create an automatic manual from indefinitely held input. Existing launch, native floor, minimum speed, unfinished trick and cooldown guards retain their gameplay purpose. Preserve once-only scoring, clean landing, overtime, resets and progression.

The owner explicitly requires genuine fore/aft manual balancing, with forward/back inputs and a vertical meter. Relabelling A/D is insufficient. Determine the correction sign from the actual board/travel/stance frame and the active manual's pose, including nose, reverse and pivot variants. Rail side-to-side balancing remains lateral; inspect lip and special balance rather than assuming every mode uses the same axis. Derive UI orientation, danger indication and corrective prompts from the same authoritative state used by physics. Remapped controls and controller prompts must remain correct.

Keep steering independent of fore/aft manual correction. Review physical rider/board lean in motion; local Euler axis names alone do not establish world-space balance because the rider often faces across the deck. Test both signs, both travel directions, normal/nose manuals and transitions between modes.

Update affected native-input drivers to the new user-approved controls, preserving their physical outcome thresholds and documenting why the old controls changed. Add independent tests that fail on the reproduced old behaviour, then run the appropriate focused cohorts and required combined regression. Capture actual meter states and a connected trick→manual→trick run using the existing native pixel/render proof. Technical success, usability, visual finish and Mac/controller feel remain distinct results.
