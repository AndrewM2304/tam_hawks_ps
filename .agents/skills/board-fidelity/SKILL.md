---
name: board-fidelity
description: Improve the native skateboard's physical construction, UVs and materials while preserving independently verified skating contacts and protected geometry.
---

Read AGENTS.md, current STATUS/interfaces, AAA_BENCHMARK V1/V3, the rider and
deformed-contact skills, board provenance, generator and actual native contact
tests before changing anything. Work within the root's file/engine leases.

1. Inspect the actual rendered board, indexed native surfaces, source generator,
   UV Jacobians, dimensions and functional markers. Source anchors are not proof
   of material contact. Diagnose real sidewall UV/thickness problems separately
   from lighting, texture filtering and intentional trick separation.
2. Use documented credible skateboard proportions and original/compatible free
   materials. Preserve source assets/notices. Record every generated derivative,
   generator hash, physical dimensions and pixel/native proof. No copied branding.
3. Preserve grip/stance planes, protected truck/wheel geometry, marker frames,
   component identities and functional contact authority unless a separately
   reviewed migration proves the entire affected contact family. Do not shrink
   geometry to hide a failed collision test. Keep legacy negative witnesses.
4. Prototype privately. Declare geometry/node/material/texture/buffer/draw budgets
   before changes. Prefer correct side UVs, plausible layered construction and
   a shared atlas over extra runtime passes. All construction is startup/offline;
   no per-frame mesh/texture generation or hidden gameplay switches.
5. Validate actual indexed vertices/indices and tangent handedness; get_faces()
   can quantize/weld and is not an exact vertex oracle. Verify protected native
   buffers/markers, close normal/shaded views, native allocation and actual
   coast/push/grind/flip/grab/manual/release contacts. Moving evidence and source
   acceptance are separate; Linux cannot certify M5 or human realism.
6. Preserve failed experiments and source-bound receipts. Independent QE reviews
   the candidate; root performs guarded main integration, full checks and push.
   A prettier atlas or passing geometry proxy does not complete V1/V3.

Native import lessons from FID-103: adding valid UVs/tangents can change Godot's
compression eligibility even when source XYZ is exact. Compare actual indexed
native positions, cached component points and protected packed vertex/attribute/
index/LOD/shadow data. A global compression override can alter unrelated grip
data. Prefer a documented narrow editor policy over runtime reconstruction, and
bind its executed source/decoder hashes inside the imported scene. Retain original
source attributes before compression; decompressing them afterward cannot prove
the original values. Validate malformed source/layout/stride/nonfinite/index
controls and keep the native engine/source-version caveat explicit.

PNG channel count also affects native texture allocation: identical decoded
RGBA pixels do not prove the same RGB8/RGBA8 resource. Inspect the actual bound
Texture2D format, dimensions, mip count and bytes, and label its API readback
separately from source/extracted PNGs and viewport draw pixels. Archive exact
reproduction inputs, requirements and derivative/licence notices. A guarded
installer must authenticate every current preimage and payload postimage before
writing; source installation still requires fresh editor/native/full validation.

Physical reconstruction is a separate migration. Derive underside, axle, hanger
and wheel-bottom datums together with every dependent floor/manual/grind/release
consumer. Validate an actual finite mounting pattern and mating surfaces; corner
agreement cannot prove whole-surface fit. A credible riser needs an attributable
wheel/setup specification, not an arbitrary height selected to keep an old marker.

Correctly touching wood/risers/baseplates can merge under coordinate-only mesh
welding. Never introduce artificial gaps or avoid matching source vertices merely
to retain a favourable component count. Preserve logical volume provenance and
authenticate complete actual indexed native triangle membership before changing
the cache authority. Keep phantom-convex-bridge negatives, missing/foreign/duplicate
face and stale-cache controls, startup resource budgets and all current contact
tolerances. Source-only construction arithmetic and semantic-part metadata are
proposals; neither is runtime clearance proof.
