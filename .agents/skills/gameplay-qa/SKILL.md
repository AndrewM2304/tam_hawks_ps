# Native skating evidence specialist

Load `.agents/skills/quality-verification/SKILL.md` first. Read current `AGENTS.md`, STATUS, runtime interfaces, `AAA_BENCHMARK.md` and the assigned fidelity-ticket clauses. Audit current main/PT24/C03 before selecting a fixture. October 17 screenshots and new patches based on that stale checkout are historical, not the November baseline.

1. Agree source freeze, import and exclusive renderer slots with root. Root owns Git and the integrated suite. If baseline source has already changed, use an explicit isolated `git archive` source copy, not a worktree or temporary replacement of another agent's files. Record exact archived SHA plus hashes of the actual executed source and observer.
2. Inspect `tools/full_fidelity_capture.gd` and its shell wrapper before launching its substantial full workload. It already provides native route/repertoire observation, same-logical-frame natural `frame_post_draw` readback, camera/Canvas synchronization proofs and lossless native-pixel hashing. Reuse those helpers for a labelled narrow diagnostic instead of building a second capture stack. Manual `force_draw` after camera changes can read the previous camera and is not accepted as equivalent proof.
3. Preserve original evidence when a wrapper uses a fixed historical destination. Keep active raw staging under `.local/`; retain exact observer/wrapper text, source inventories, command, logs, frame hashes and receipt with the new evidence packet. Label every initial reset, authored camera, full-meter/unlock fixture and frozen-contact reconstruction. Script/test launches must neither persist nor control personal Apple Music.
4. Inspect ordinary chase plus authored views of all six areas and connected corridors. Review rider anatomy, garment attachment, hands/shoes/board, ground material scale, windows/roofline seams, support holes, repetitive strips, landing sightlines and visible next choices. A clean shader log and saved PNG count are not a visual verdict.
5. Review normal-speed motion and frame-step worst transitions. Native timeline observations must have no omitted physics ticks. Record input, real trick/landing/capture/bail events and actual body/board/camera transforms. Distinguish intentional trick separation from contact glitches; no per-frame position, velocity, heading or score injection is allowed in a claimed natural route.
6. Audit both directions, alternative line and safe bypass. Measure opportunity intervals using the actual ordered features plus the no-feature return leg; a `closed_loop` label does not prove useful density. Test approach/landing/runout and deliberate misses, not only selected successful jumps.
7. Use existing focused tests first, then the root-coordinated `./tools/check.sh` for production changes. Retain failed receipts. Keep physical support, connected combos, automated controls, rendered appearance, human fun, actual Mac launch and MacBook Air M5 sustained timing separate.
8. File concrete `FID-D###` defects with source, fixture, actual/expected, frame/sample, severity, owner, clause and retest. Update `docs/testing/FIDELITY-REVIEW.md` with only directly inspected outcomes. A software-rendered fixed-fps replay cannot certify target hardware or AAA finish.

9. For native skinned-cloth/contact witnesses, inspect the exact renderer equation before reusing a CPU oracle. Godot4.6.3 skins raw decoded weights in local coordinates and applies the actual MeshInstance model once; world-per-influence and the native CPU mesh-bake API differ for valid nonunit UNORM weights. Use actual nonidentity bone motion, unequal mesh/skeleton frames and a detached-Skin negative at far origins. The [independent native operation-order packet](../../../docs/testing/fidelity-2026-11-06/skinning-operation-order-01/README.md) supplies a bounded GLES recipe; it does not certify later fitted-rig selection or target hardware.
10. In new authored asset observers, retain both source inventories, numerical camera/projection and actual root/head/bone/board transforms, before/after counters and poses around each native proof/clean readback, plus PNG and decoded RGBA hashes. Independently project marker centroids; exclude stale output files absent from the current receipt. Disclose missing Canvas or unique frame signals and static authored-state limits. Internally asserted parity and a saved-file count are weaker than retained independent evidence. Preserve rejected epochs rather than repairing receipts after execution.
11. Resolve native Skin bindings by nonempty name before numeric index; missing names fail closed. Use a real `SkinReference`/RenderingServer palette and native pixel witness when helper resolution is in doubt. For rendered attachment, compare the actual current Skin palette with each rigid/skinned mesh's rendered model at the same readback. `get_global_transform_interpolated()` can include an interpolated ancestor even when the child is OFF; do not substitute current globals solely because the child's interpolation flag is OFF. A current-pose seam calculation can pass while the visible head/garment separates.
12. Authenticate selected seam points through actual indexed triangle incidence and declared source boundary edges. Unindexed orphan coordinates, unordered triangle triples that hide reversed winding, or nonfinite UV/normal comparisons cannot establish native source identity. Keep import-format identity bounds separate from contact tolerances and add malformed topology/attribute negatives.
13. Use one natural draw and `frame_post_draw` barrier per claimed physics tick in a consecutive motion sequence. Multiple view buffers from that same draw are valid when exact same-frame counters, transforms and pixel proofs establish their identity. Use separate side/chase full-prefix replays when an additional draw advances physics; preserve the rejected attempt rather than stitching missing ticks. Keep native physical trace equality separate from unmatched-prefix image comparisons. Compact lossless WebP is permissible evidence preservation only after independently decoding and matching every native RGBA hash, retaining original PNG hashes, exact runtime metadata and selected original PNGs; label it as re-encoding and keep full ignored originals.

14. Pin inspected public engine source and record the actual installed engine version/full commit identity and binary fingerprint. A matching release name alone does not prove exact source parity. If commit identities differ or source is unavailable, disclose that limit and use actual native palette/model/query/pixel witnesses for installed-binary behavior; do not retroactively invalidate or rewrite those independent observations.

Repository briefs/skills persist across sessions and must be explicitly loaded. No unattended loop, paid tool or automatic agent registration is implied.
