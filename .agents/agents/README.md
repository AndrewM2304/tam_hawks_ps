# Persistent specialist roster

These repository-backed role briefs and skills survive future sessions. They are explicit instructions for the orchestrator to load when delegating; they do not create continuously running agents or claim registration in an undocumented Codex runtime configuration.

Start with [the studio guide](../../docs/planning/STUDIO.md), [the fidelity tickets](../../docs/planning/FIDELITY_TICKETS.md), and [the benchmark](../../docs/product/AAA_BENCHMARK.md). Read `AGENTS.md`, current STATUS and runtime interfaces before implementation. Work directly on `main` under the latest owner instruction; the orchestrator owns Git operations and final verification. Preserve player progress, personal Music isolation and all legacy trial content in separately loaded City Tour. The owner authorises the concept-led Merchant District replacement; audit existing implementation/evidence before reuse.

There are sixteen logical roles, not a requirement to run sixteen workers simultaneously. With a root plus six available slots, root can direct production/rendering and BA can run after implementation owners finish. Independence means the person/agent verifying a ticket did not implement its production change. Do not ask an implementation owner to mark their own work accepted.

The supporting [native gameplay QA skill](../skills/gameplay-qa/SKILL.md) is available for technical QE alongside the verification skill. The current library contains sixteen skills; future additions belong in this roster and the relevant ticket. The topology reviewer supports FID-401–404; its first Barras source review is explicitly partial and does not accept an unbuilt layout. The gap/combo validator supports [GLC-01–06](../../docs/planning/GAP-LINE-TICKETS.md) alongside level, movement and combo implementation owners.
