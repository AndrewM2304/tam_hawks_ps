# Prototype interfaces

Godot 4.6.3 with the Compatibility renderer. Native GDScript with one adapted MIT rail-geometry helper; no plug-ins or downloaded game assets. Scene geometry is procedural and fully original. Coordinates: +Y up, player forward is local -Z, ground surface Y=0, spawn `(0, 0.8, 12)` facing -Z. World bounds approximately X ±35, Z ±42.

## Input actions (registered by game/core/input_setup.gd)
`push`, `brake`, `steer_left`, `steer_right`, `ollie`, `flip`, `grab`, `grind`, `spin_left`, `spin_right`, `restart`, `pause`, `free_skate`.
Keyboard: W/up push, S/down brake, A/D or left/right steer, Space ollie, J flip, K grab, L hold grind, A/D balance on rail, Q/E spin, R restart, Escape pause, F free skate. DualSense through SDL standard mapping: left stick push/brake/steer, Cross ollie, Square flip, Circle grab, L1/R1 spin, R2 hold grind with left-stick balance, Options pause, Triangle restart, touchpad free skate. Physical mapping requires hardware verification.

## Skater — game/player/skater.gd
Extends `CharacterBody3D`, instantiated by main. Owns body meshes, movement, trick timing, and camera. Public properties `speed: float`, `airborne: bool`, `spawn_position: Vector3`; signals `trick_performed(trick_name: String, points: int)`, `landed(clean: bool)`, `bailed()`. Public `reset_skater()` restores spawn and physics; `set_controls_enabled(enabled: bool)` gates input. Emit landing only when transitioning from airborne to grounded; do not score held-button tricks repeatedly. Main handles combo/total scoring. Flat ground landing succeeds; over-rotated/unsafe landing may bail only if documented. Ramps use ordinary static collision. M01 takeoff fixes preserve collision-adjusted planar momentum and use capped actual ground velocity. M02 adds held rail capture/travel with balance; manuals and reverts remain future work.

`set_grind_lines(lines: Array)` receives world-space geometry snapshots. `grinding` and `grind_balance` expose current rail state to main/HUD. Capture requires airborne descent, held grind, speed/angle/proximity gates and a swept clear path. `GrindRide` owns track progress and balance; skater owns capsule sweeps, pause/reset/release and a 0.35-second global recapture cooldown. Air spin is resolved once on rail entry without emitting a landing/bank. Rail entry awards 200 once; release retains tangent velocity. Only actual ground landing banks the combo. `set_trick_entries_enabled(false)` freezes new trick/spin/capture inputs during bounded overtime while allowing an existing ride to release and land.

## World — game/levels/glasgow_square.gd
Extends `Node3D`, instantiated by main. Generates a readable, skateable fictional Glasgow square with static collision, ramps, ledges, boundary walls, buildings, cone-topped statue, signs, and lighting/environment. No external resources. `get_spawn_position() -> Vector3` returns `(0, 0.8, 12)`. `get_location_name(position: Vector3) -> String` returns a district/landmark label. `get_grind_lines() -> Array` returns two fresh geometry snapshots from rail-local authored vertices. Rebuild after transforming the world. Rail bars/supports occupy layer 2 (mask 0), while ordinary scenery is layer 1 and rider masks layer 1. This intentionally makes rail props nonblocking unless acquired by the explicit grind controller; normal ground travel cannot score them. World owns visual geometry and collision; no scoring, input, or player creation. Keep central path unobstructed and all slopes skateable.

## Score — game/scoring/score_session.gd
Extends `RefCounted`. Holds `total_score`, `combo_base`, `combo_multiplier`, `best_combo`, `last_trick`, `last_banked`, `trick_history`. `add_trick(name, points)` accumulates with repeat-trick degradation; `bank_combo() -> int` awards combo and resets; `drop_combo()` loses active combo; `reset()` resets the run. `get_combo_value() -> int` computes preview.

## Main and UI
`game/main.gd` creates world and skater, wires signals to scoring, implements 120-second runs, free skate, pause/restart, and passes snapshots to `game/ui/hud.gd`. HUD extends CanvasLayer with `update_display(snapshot: Dictionary)`; UI controls emit restart/pause/free-skate signals. Timer runs only during active play. Active air/rail combos have a hard three-second landing grace; expiry rejects new tricks/rail entries. Immediate landing bank is retained until M02-004/005 implement the documented continuation window. The root orchestrator owns these files.

## Rail geometry — game/tricks/grind_line.gd
Adapted MIT `GrindLine` extends `RefCounted`. Constructor `(id, world_points: PackedVector3Array, optional_kind)` builds a world-space `Curve3D`; `from_local_points(id, points, authoring_transform, optional_kind)` snapshots transformed authored points. `is_valid` requires finite geometry and nonzero length. `point_at(distance)` clamps to endpoints; `dir_at(distance)` returns the full 3D unit tangent for positive progress; `closest(world_position)` returns `{dist, point, gap}`. Invalid sample requests return zero vectors and invalid closest queries return `{}`; callers must check `is_valid`. Distances are world metres; recreate after changing parent transforms. The first grind state now wires this helper to two visual rails. The MIT source and full notice remain unchanged.

## Ride state and trick definitions

`game/tricks/grind_ride.gd` is an original `RefCounted` controller around the adopted geometry. `start(lines, from, velocity, clearance)` selects the nearest eligible unobstructed line; `step(delta, balance_input)` returns `riding`, `end`, `bail`, or `slow`. `position()` and `travel_velocity()` retain the release sample; `stop()` deactivates the ride. Public fields expose active line/distance/direction/speed/balance/elapsed. Root integration supplies actual capsule collision sweeps. Geometry/ride helpers are tested separately from the production player.

`game/tricks/trick_catalog.gd` supplies validated copy-returning definitions, known-ID/state guards and repeat arithmetic. ADR-006 separates current enabled behavior from future manuals/reverts/specials and the 0.35-second landing window. Catalog presence does not enable a feature. Main still owns score/session resolution.

## Testing
`godot --headless --path . --editor --import` validates imports. `godot --headless --path . --script tests/run_tests.gd` runs focused unit/integration tests. Use writable XDG data/cache/config directories inside `.local` in this cloud machine. Rendered capture is separate from headless physics tests. No remote services or runtime secrets required.
