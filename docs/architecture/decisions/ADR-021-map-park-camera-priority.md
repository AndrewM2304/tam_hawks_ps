# ADR-021 — Prioritise map continuity, park skating and camera flow

19 October 2026. Status: Accepted direction from the owner's explicit request; implementation and acceptance open. Owner: A01.

The owner reports missing map between spawn/main area and Kelvingrove, sparse grass with little skating purpose, unfinished world/UI views, and poor ramp-camera behaviour. The owner requests a recorded implementation plan and review of outstanding tasks, using linked THPS 3+4 footage as a movement/camera/line reference.

Follow [MAP-FLOW-REPAIR-2026-10-19](../../planning/MAP-FLOW-REPAIR-2026-10-19.md). Reproduce and repair current connector/world continuity first; address tighter camera framing and ramp response; survey a coherent park/port contract; add a central half-pipe, bowl and street section linked to downhill rails/benches. Fix verified UI clipping after viewport reproduction, with final map alignment after geometry changes. These are refinements within the existing map, not another district. User direction authorizes the park content; exact geometry remains subject to physical and performance validation.

This order supersedes older unconditional horizon-before-park and path-only compact-park sequencing. It integrates HORIZON-03/04, PLAY-02/03/06 and DENSITY-02/shared seam work without deleting their requirements. Independent broader core compression, optional encounters, rejected facade/mural experiments and final release packaging follow these repairs. No engine/interface change is approved by this plan alone; publish any bowl support extension before implementation.

Preserve skating-first, no-spend, existing source licence/reuse rules, stable save/goal/encounter identities, native camera collision/comfort protections, offscreen gameplay, skyline and strict frozen matched rendering gates. Resolve measured stutter before added rendering cost. Reclaim surplus park construction to fund the central destination; declare actual numeric baseline counts before source changes. Historic automated passes cannot dismiss new owner-reported faults or supply human/Mac/DualSense acceptance.

This checkpoint is planning only. Full backlog ticket bodies/statuses remain preserved; new local MAP tasks carry the actionable refinement and [outstanding snapshot](../../planning/OUTSTANDING-2026-10-19.md) exposes all non-Done records for review. No remote issues, publication, new assets or gameplay changes are included.
