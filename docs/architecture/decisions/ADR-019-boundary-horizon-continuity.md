Measure this cost separately if the combined candidate fails. No new PBR normal/roughness maps or per-frame shader animation.

## River preview correction

The first six-view native preview improved park/civic depth but rejected the bright generated tile and still showed clipped water behind abruptly ended banks. Reuse the resident CC0 brick ALBEDO only on the existing high guard; ship no generated wall tile. Extend tiny art-only bank strips beyond existing blocked quay ends into southward river bends (both ends avoid the existing park). Replace only the displayed water mesh, reusing its original animated ShaderMaterial, so coplanar water patches never overlap. Do not extend supported ground, collision, routes or recovery promises. Native central water X[-85,85]/Z[78,116]/Y−2 remains; scenic shore/back vertices and unchanged protected ports must be independently proved. Four static chunks contain678 footing/service-back and72 scenic-bank triangles; the replacement water has18 triangles. Combined768 ceiling, no extra water submission, no new shader/material for water. Skyline cannot substitute for this geometrical river continuation.

The first independent run exposed an endpoint-interpolated service panel floating over the loading bank and a DXT1 seam despite equal edge pixels. The corrected service back is the fixed construction plane above, embedded in the existing plinth; raw boundary footings stay exact. Native DXT1 dithering varied the first/last columns even in byte-identical blocks. Constant RGB565-representable4×4 border blocks remove that source of decoded wrap error; only8/4096 columns change. The imported image must still pass the original pixel threshold; do not raise it. Native octahedral normal packing is verified with its small angular error rather than requiring zero component error after import. Rejected logs/source remain in the evidence packet.

A subsequent native block dump showed the raw outer-texel test also mistook ordinary DXT1 dithering for a unique seam: byte-identical edge blocks repeat a4-column pattern whose last/first pixels naturally differ. Keep the original.04 colour threshold for decoded4-pixel edge means, verify exact source border continuity and equal decoded edge patterns, and report raw texel jumps separately. Do not claim pixel-perfect compressed texels. Actual wrap-facing captures remain the composition gate. The corrected predicate reflects native codec behavior; it does not raise a failed colour tolerance.
