# Ramp spin comparison — 22 October 2026

The owner rejects the demo's unnatural automatic body 180 and requests dramatic separated-board bails and a HUD closer to THPS. These are higher-priority refinements to BAIL-R02/R03 and MAP-03B/MAP-07; existing park/world work remains open.

Inspected the actual `HandleSpin` and `DoInAirPhysics` source files at LANCommander/THPS revision `fa128f5ba222e0f24a9bff019d59262b79141e48`. [HandleSpin](https://github.com/LANCommander/THPS/blob/fa128f5ba222e0f24a9bff019d59262b79141e48/decomp/src/physics/handlespin.cpp) queues tap turns from shoulder-button triggers, derives lean/turn from analogue/directional/shoulder input and tallies scored rotation. [DoInAirPhysics](https://github.com/LANCommander/THPS/blob/fa128f5ba222e0f24a9bff019d59262b79141e48/decomp/src/physics/doinair.cpp) applies a turn derived from the lean field, updates rotation/angle tally, calls `UprightSideways` conditionally and resolves world collision. `FlipToVelocity` appears in its wallride collision entry, not as proof of a universal apex yaw. Helper internals and numbered state semantics have not all been traced.

A further helper check prevents overgeneralizing that finding: [`UprightSideways`](https://github.com/LANCommander/THPS/blob/fa128f5ba222e0f24a9bff019d59262b79141e48/decomp/src/physics/uprightsideways.cpp) applies a small local roll based on front/world-up/up-vector products, while [`FlipToVelocity`](https://github.com/LANCommander/THPS/blob/fa128f5ba222e0f24a9bff019d59262b79141e48/decomp/src/unnamed/800429d0.cpp) conditionally negates front/right matrix columns and toggles a flag. That is an automatic heading-flip helper, distinct from an input-scored spin; its name alone does not prove a smooth 180 apex animation. The inspected call in DoInAirPhysics is a wallride-entry path. The [ground routine](https://github.com/LANCommander/THPS/blob/fa128f5ba222e0f24a9bff019d59262b79141e48/decomp/src/physics/doonground.cpp) calls that helper when `!OnInvisible && !mInAir`, alongside state-conditional support/orientation/collision handling. Thus “all turning is input only” would be too strong; ordinary spin, roll correction, velocity alignment and vert animation must be distinguished. The helper's numeric threshold uses uncalibrated source units and is not imported as a Godot tuning constant. No verified THPS3 apex-turn timing or skeletal animation follows from these files.

Our previous `_update_pose` instead used `smoothstep(-2,2,-velocity.y)` to force an unrequested half-turn about the ramp normal, then used that same frame for both body and camera. That is a local implementation, not established reference behaviour. The replacement separates the camera arc from a slower assisted body half-turn, adds knee/shoulder anticipation and retains player spin as a separate layer. The old +2…−2m/s band lasted ~0.18s at current gravity; the new +6…−6 band lasts ~0.55s. A fixed-axle pitch candidate was rejected because it faced the head into the wall on descent and failed existing framing checks. The retained assisted return is still our tuning. It is not evidence that THPS3 executes this exact motion, or that the THPS1 reconstruction fully describes THPS3 vert/fakie animation.

The source is a community reconstruction of original THPS, with comments drawing on demo symbols. THPS3 remains the intended gameplay reference. No verified THPS3 constants, animations, ragdoll implementation or exact recovery timings are claimed. No reconstructed source, game assets or animation was copied or executed. Primary source files were fetched as public raw HTTPS data into ignored research storage; hashes/byte lengths are in [the source receipt](THPS-RAMP-SPIN-SOURCES-2026-10-22.json). We now use the existing native body capsule for the skater's fall/slide, original reachable-limb fall/get-up poses and one independent native rigid board reusing the original mesh. The board is reclaimed after the recovery gate; this is a deliberate arcade restoration, not a physical pickup animation or full-body ragdoll. Human motion/art acceptance remains open.
