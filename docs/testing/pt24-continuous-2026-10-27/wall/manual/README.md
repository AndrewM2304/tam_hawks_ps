## Finite geometry proof and cost

Each proposal has two current loaded-tyre rays and three native volume queries
for the complete board convex hull and cached shoe envelopes. Every loaded tyre
vertex needs its existing support skin. Acquisition uses a live native board
rest contact and short same-collider vertical-face ray. The **18 cm** root limit
and **7.99 mm** native query margin are unchanged.

The backend can report floor touching even when the complete board envelope is
about 8.03 mm above the floor. Only the exact currently supported **RID and shape
index** can qualify as harmless floor contact. The solver computes the highest
point of that entire native Box or bounded Convex primitive along the authenticated
support normal, then requires every point of the complete query hull/box to lie
at least 7.99 mm above it. This proves whole-shape separation directly; the rounded
ray-hit height has no authority to weaken clearance. Other native primitives,
oversized point sets, capped hit lists and every different shape remain refused.
A compound body's other shapes are never excluded.

Candidate order is decayed fit → freshly derived finite minimum → retained
fallback. The worst path remains **17 DirectSpace calls**: 5 + 2 + 5 + 5. When
decay fails, deriving the fresh minimum can add two calls before a formerly
accepted retained fit; that bounded work removes stale excess during pose fade.
Clear ordinary Manual adds one rest query; clear non-Manual skating adds none.
No query or shape resources are created by this path. The finite separation proof
reads at most 4,096 board hull points (currently 3,729), up to 64 floor-convex
points and analytic shoe boxes per proposal. Target-Mac timing is unmeasured.

Controls cover repeated no-accumulation solves and all query fields including
nonzero motion; unearned residual, graded/one-tyre support, over-limit offset,
secondary side wall, another wall shape sharing the floor RID, a 1 mm raised
blocker, a shoe below the floor despite valid tyre rays, unsupported WorldBoundary,
wall removal, bail and restart. Removed-wall offset decays to **0.158195 mm**
after 18 ticks. These safety refusals are retained rather than widening the fit.
