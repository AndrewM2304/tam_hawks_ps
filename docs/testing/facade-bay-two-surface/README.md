The first [dark diagnostic](dark-diagnostic/receipt.json) passes the same structural checks but lacks the production sky; it is inadequate for material quality. The corrected fixture copies `_build_lighting` sky/radiance/ambient/fog/sun/ACES, uses the actual west-frontage yaw, and shares an identical simple floor/apron/mass shadow. It retains the source function's 75 m shadow range, rather than the active Balanced preset's 45 m override. This is an isolated source-lighting comparison, not the full city or a Balanced timing workload. Both trials retain all 39 PNGs, logs/import configurations and source bindings; no import cache, copied GLB/texture payloads or player profile is committed.

Near/mid/far geometry is **9,864/3,544/648 triangles**, two opaque surfaces versus four at the fitted reference's 18,392/3,544/648. Original stone maps are shared. The built-in accent ORMMaterial3D has white albedo, a colour atlas and one packed linear ORM; only ORM mip generation is disabled. Actual ORM readback is 128² DXT1, 8,192 data bytes, no mips; all colour/stone maps retain their 10 mip levels. Candidate/reference imported texture data is 3,503,512/3,495,320 bytes: **+8,192 bytes**, not a resident-GPU-memory or FPS measurement. Actual compressed ORM maximum channel error is paint 0.009725, glazing 0.012005 and metal 0.027055, within the declared RGB565 tolerance.

**Visual quality is still open.** Root inspected close, oblique and far pairs; A05 inspected all 16 corrected originals. Doors, threshold, reveals and staged silhouettes remain aligned. The broad paint fascia/pilasters show repeating bands: the authored rectangle has one RGB value `[47,82,73]`, while the actual compressed import repeats four values ranging `[41,81,66]`…`[49,85,74]`. No-mip ORM also dithers roughness 121…125 around authored 122; chamfer normals independently change some highlights. [Diagnostic data](production-sky/paint-diagnostic.json), [method](diagnose_paint.py) and [close comparison](production-sky/candidate-02-close.png). Imported colour compression and coarse mip 7+ region mixing are not accepted by the offline uncompressed sampling result; metal mip 10 maximum linear-channel error reaches 0.095279. These values do not identify the GPU-selected mip level. The original bad ORM mip 4 counterexample remains in source-asset-audit.json.
