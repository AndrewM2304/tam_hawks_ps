# Native board UV04 — bounded admission evidence

The original collapsed side UVs are repaired while preserving the board's actual
geometry and contact cache. This is a UV/material improvement. It does not repair
the inherited 28 mm wood, misplaced mounting bolts, tall truck arrangement or
establish complete skateboard realism, moving Main acceptance or M5 performance.

`76103e39e5ed91c5c8381d38c58af8272915952f000ba475dbda30206b7d0943`.
The UV04 RGB image has exactly the same decoded RGBA pixels as UV03; every
primitive's attributes and indices are also identical to UV03. Removing unused
alpha restores the original native RGB8 allocation. The original project-owned
base remains `d5a68a8b…15431f99`; no external visual content or branding is used.
