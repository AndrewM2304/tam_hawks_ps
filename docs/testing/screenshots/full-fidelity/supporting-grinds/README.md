# Scoped wide-coping contact evidence

These are byte-exact copies of the existing before/after inspection receipts,
recipes, raw local render logs and two actual Main close views. Original receipt
paths and source hashes remain unchanged; `archive-receipt.json` maps each source
file to its saved copy and SHA-256. This is scoped contact evidence, not the final
movie, a played ground approach, visual acceptance or Mac performance evidence.

The identical recipe declares one descending initial contact above the actual
`clyde_quay_coping` track. Held Grind then uses production native clearance and
capture. Neither continued motion nor the board/rig pose is injected. The probe
tests actual visible board mesh vertices against the complete finite native
BoxShape or CylinderShape volume, including the cylinder's curved boundary.

Before, the broad box crown contained 168 tyre vertices, 14.47–18.02 mm deep.
After the four wide ledge/coping bars received matching visible/native rounded
crowns, the same fixture contains zero tyre or other board vertices inside the
finite solid. Both runs retain an actual crown/path gap of 0 mm, one capture,
one score entry and no bail. The after render reports 2 passed, 0 failed.

Inputs are unchanged within each run. Across the pair, OutdoorRoutes contains
the rounded-crown repair and the rig also contains the separately tested ordinary
push/brake repair; that repair's gates are false in this grind fixture. The
recorded board and visual rotations, bearing point and score receipt are
identical. No grind pose offset or contact threshold was changed.

A later headless rerun of the existing four-track fixture reports **7 passed,
1 failed**. Thin Exchange rail, repaired Court edge and rounded Clyde coping all
maintain capture and clear actual finite solids. Gallery Entrance retains correct
crown bearing and capture, but five front-tyre vertices enter its upcoming
diagonal cylinder by at most 4.22 mm before the rider reaches the sharp polyline
bend. This small corner sweep remains open; it is not the previously withdrawn
wheel-to-ground floating interpretation. The final-four receipt/log preserve
that failure rather than expanding the wide-coping result into full acceptance.
