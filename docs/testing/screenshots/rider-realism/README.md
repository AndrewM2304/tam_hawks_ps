# Adult rider inspection

Actual Godot 4.6.3 Compatibility captures, 17 October 2026, 1280×800. No generated or retouched pictures are used. [RIDER-REALISM](../../RIDER-REALISM.md) records implementation, checks and remaining limits; [human reuse](../../../research/HUMAN_MODEL_REUSE.md) records the CC0 anatomy source.

Run `./tools/rider_capture.sh` for the actual-input action sequence. Output is `.local/rider-capture/`; selected frames are copied here. The close cameras are authored inspection views, and the two specials use a full-meter fixture. Physics runs at 60 Hz. Rendering freezes only after each requested state has been reached.
