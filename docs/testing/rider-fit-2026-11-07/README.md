These are original unmodified native Godot frames from a private isolated art
project that copies the production visual/animation rig. They are **not normal

AAA pass**. The actual runtime remained frozen for the separate integration
checkpoint while these licensed asset experiments ran in ignored local storage.

source hashes and independently projected red/green/blue marker pixel proofs for

retained raw engine logs report 9 frames / 0 proof failures. Those technical
