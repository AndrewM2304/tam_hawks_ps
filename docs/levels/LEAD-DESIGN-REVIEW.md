# Lead level-design review: Glasgow routes

**17 October 2026.** Reviewer role: senior skate-game level designer perspective, without claiming to be an actual Tony Hawk's developer. Requested references: THPS4 San Francisco/London, THPS3 Los Angeles, THPS1 School and THPS2 School II. [CLASSIC-LEVEL-DESIGN](../research/CLASSIC-LEVEL-DESIGN.md) distinguishes inspected source facts, interpretation and mechanics that are currently unsupported.

## Review judgement

The terrain redesign is a meaningful improvement over the original flat sandbox: it supplies six named places, actual 0→17 m terrain, a curved grindable fountain, raised station decks, stairs/banks and a real optional Clyde transfer with a safe bridge. **It still needs more spatial composition to meet the owner's latest brief.** The inspected six-area overview reads as four large rectangular courts connected by straight streets, with a park loop on a long approach and a broad river frontage. Adding names, facade variation or more isolated ramps will not fix that structure by itself.

The accepted implementation slice creates enclosed connections, routes crossing at different heights, and shorter return choices. Geometry work is explicitly authorized by the owner's request; preserve the ten existing career/save IDs while changing the playable map. Four concrete improvements were agreed with the geometry owner for this session, below. **Their production source and corrected rendered evidence are now inspected; the bounded topology slice is accepted as a substantial development iteration. Final integrated package checks and human/final-art acceptance remain separate.** The initial diagnosis describes the baseline capture set, while the implementation contracts and final judgement below describe the additions. Do not present the baseline images as proof of the new routes.

### Explicit continuation tasks for missing big features

The planning owner has recorded the following in [BACKLOG](../planning/BACKLOG.md) with owner, priority, dependencies, acceptance and test strategy. They are concrete continuation work, not completed mechanics:

- **M02-011 — Transition skating study (P1 after current route stabilization):** compare free compatible slope/vert-controller approaches against the existing movement/landing/grind state machine. Prototype one original bowl/quarter-pipe in an isolated test scene, with matching mesh/collision, deliberate grounded→vert→air/re-entry and camera behavior. Test normal/fast/slow/diagonal entry, apex, landing/revert, bail and low-speed rollback. Integrate only after it can coexist with the existing ten-goal circuit; retain the current bank bypass.
- **M02-012 — Wallride/wallie mechanics (P2):** explicit eligible angle/speed/contact state, bounded travel, intentional exit/ollie, no repeated-award exploit, interruption/recovery and camera tests. Only then author an original optional close-wall shortcut. Decorative walls do not close the ticket.
- **M03-015 — One original changing-route set piece (P2):** design a fictional service gate/bridge mechanism or similar Glasgow-flavoured event with clear setup/payoff, reversible/resettable geometry and a permanent beginner exit. Define career/free-skate/save behavior and test collision switches, double activation, pause/bail/restart, trapped-player prevention and route-map update. Coordinate with the fun agent.
- **M02-013 — Skitching/moving traffic assessment (P3):** decide whether it improves this compact map before implementation. If chosen, author original vehicle paths, attachment/balance/release state, momentum, obstruction/camera handling and reset rules; first demonstrate it in a test scene. No traffic/assets/services need purchase.

These tasks prevent unsupported classic mechanics from disappearing from the plan while keeping this session focused on substantial playable level geometry.

## Agreed implementation slice

### 1. Station undercroft and upper route — P1

**Purpose:** a real high/low choice in one compact place. The same canopy landmark should be recognizable above the platform and through the lower passage.

The filled upper walk/platform collision is replaced where necessary with 0.40 m-thick suspended Y5 decks, retaining the Y2 concourse and existing Y5 platform gap geometry/goal positions. Final `station_low_level_close` follows `(−126,2,0)` → `(−126,2,−8)` → `(−114,2,−8)` → `(−103,2,−8)` → `(−82,2,−8)` → `(−82,2,22)`. The underside is Y4.6, providing 2.6 m over the lower floor; independent capsule and chase-camera evidence still decide usability. The west canopy column at `(−124,−10)` moves north to Z−17 rather than remaining in the entrance. Side columns/visible beams make the suspension plausible without filling the passage again.

**Choice:** low continuous concourse line; high bank→platform gap→exit line. A miss should return to the concourse. **Reveal:** a clear daylight exit and the canopy beyond; avoid an unreadable dark slot. **Acceptance:** drive under the actual upper collision both directions, inspect the underside/head clearance and exits, then complete the preserved high career gap. Floor raycasts from above cannot by themselves prove two-height traversal.

### 2. Merchant Close dogleg and pocket — P1

**Purpose:** an enclosed Glasgow-style close linking two existing places through a distinct bent corridor. It is an original composite close, not a claim about a particular real lane.

Final 8 m-wide `merchant_close_cutthrough` centreline: `(−64,2,−30)` → `(−68,2,−44)` → `(−69,2.5,−50)` → `(−61,3.2,−60)` → `(−55,3.5,−65)` → `(−59,4,−74)` → `(−59,4,−80)`. The mouth stays Y2 until it clears the station floor; this corrects a curb found by the career route check. Real angled retained terrain strips, junction aprons and two solid facade islands frame the route. The northern mouth rejoins the civic back street; the southern mouth rejoins Central's northern street. The existing X−22 gallery/career approach stays clear. A triangular side pocket and low angled ledge widen the middle bend; the new surface occupies previously unsupported negative space, rather than drawing a path over an empty square.

**Choice:** existing broad outer road or tighter close; continuous low route or optional ledge/bank line. **Reveal:** from the southern mouth, see a corner sign/open pocket, then reveal the higher civic skyline after the dogleg. **Acceptance:** both directions clear at production capsule width and realistic steering speed, no terrain crack, enough turning space at all grade/corner changes, and a visible exit from each bend. Record an actual optional combo attempt separately from the transit check.

### 3. Kelvingrove cutback return — P1

**Purpose:** a second descent that rejoins the city approach, making the hillside a route choice instead of one principal riding loop reached by a long spine.

The continuous 8 m `kelvingrove_cutback_return` path uses these initial knots from the upper western bend: `(−208,11,−126)` → `(−226,10,−111)` → `(−210,8,−86)` → `(−185,6.5,−70)` → `(−162,5,−54)` → the existing station approach near `(−147,4.5,−48)`. Final sampled heights blend around a common Y11 fork apron (6 m flat radius,14 m blend) to avoid a branch seam. Surrounding grass terrain follows the new branch so it is an embanked path, not a floating ribbon. Existing paved ascent and rolling summit loop remain. An optional short ledge/bank transfer sits beside the path; continuous riding is the beginner bypass. Trees stay outside the approach and camera corridor.

**Choice:** continue around the summit loop, take the shorter descending cutback, or climb it in reverse. **Reveal:** station canopy/city skyline in the downhill direction; a visible junction at the branch. **Acceptance:** traverse every seam in both directions with actual uphill/downhill physics, rejoin the original station approach without a step or forced stop, and inspect chase views from the branch and final join. No required ollie or vert mechanic.

### 4. South-Clyde landing pocket — P2

**Purpose:** give the risky bridge landing a compact destination and return line instead of a wide empty south bank.

The Y2 `clyde_print_yard_loop` runs from bridge landing `(35,2,116)` → `(35,2,124)` → `(56,2,137)` → `(78,2,124)` → `(45,2,122)` and back to the south quay. A small original print-yard/planter island near `(58,2,127)` makes the turns meaningful; an 8 m paving strip and matching openings in the Z130 backing wall frame the route. The existing X38/Z145 facade stays behind the route. A low ledge edge and the island bank add optional actions after the bridge. The continuous south-quay path and safe bridge remain open.

The geometry owner accepted a real low **curved bank and rounded hip** around the print-yard island, bounds X53.5…62.5/Z124.5…129.5, at ground Y2/top approximately Y2.723. The sampled circular profile has radius4 m, angle0→35°, horizontal run2.294 m and rise0.723 m. East and south faces meet around `(62.5,129.5)`; their toes lie near X64.794 and Z131.794. The route centreline stays outside those toes. Verify ascent, crest and descent and an optional air/landing with the actual controller. This is a shallow curved bank/hip using supported floor angles; it is not a working vert quarter-pipe, bowl, lip trick or spine-transfer system.

**Choice:** bridge transfer → pocket → quay, or safe bridge → promenade → pocket. **Reveal:** bridge/river skyline stays readable on return. **Acceptance:** land the existing transfer, enter/exit the pocket on actual collision, return along the quay without a blind obstacle, and test the continuous beginner circuit separately. A rearranged planter alone is insufficient without the angled route and reconnecting exits.

## Acceptance and next review

1. **Topology:** the production route map shows the undercroft crossing, dogleg, new park return and quay pocket; each declared continuous route is physically supported and rejoins existing play. A new node name is not evidence of a new route.
2. **Movement:** independent tests use the real production body and input for new routes in both directions, upper/lower station access, career completion and any changed collision joins. Tests may directly aim grounded heading only if the idealized limit remains explicit. Preserve the 120-second career requirement, all ten goal/save IDs and free-skate progression protection.
3. **Flow:** demonstrate at least one actual linked local combo through the new street/pocket elements, and keep an ordinary supported bypass. If no such run is performed, document the feature arrangement as unverified combo potential.
4. **Readability:** source-stable rendered chase views at both close mouths, under the station deck, at the park branch/join and Clyde landing/pocket. Review approach, takeoff, landing and next exit; use an overview to assess overall shape, not to substitute for the chase camera.
5. **Place:** solid facade/retaining islands, ground materials, foundation joins and skyline frame routes. Glasgow names on generic isolated ramps do not close this gate. Current business frontage authenticity still requires dated inspected reference; this slice uses original composites.
6. **Human fun:** leave difficulty, camera comfort, route discovery, replay appeal and final presentation open until a human plays. Automated ten-goal completion and smooth screenshots cannot certify those outcomes.

The immediate post-implementation review should compare the new actual screenshots with the four reviewed baseline frames and state exactly which objections were resolved. Remaining empty court edges, repetitive facades, unsupported advanced mechanics or overly long approach segments must be carried forward as explicit tasks, not hidden behind a completion claim.
